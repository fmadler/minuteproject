# Manage template definition

## Tracks and templates
A Track correspond to a technology target (ex: SpringBoot).

A track is composed of one or more target, a target is composed of some template-target.

template-target contains a list of templates.

## Template
A template is composed of multiple attributes

### Attributes
Choose your template type:
* table/view
* column
* field
* model
* package
* query
* query-input
* query-output
